# Cache Memory Simulator

Модель кеш-пам'яті, реалізована мовою **C++**, яка демонструє принципи роботи прямого (детермінованого) відображення кешу та алгоритму **Write-Back**. Проєкт розроблено в рамках лабораторної роботи з дисципліни **«Операційні системи»**. :contentReference[oaicite:0]{index=0}

---

## 📖 Опис

Проєкт імітує взаємодію кеш-пам'яті та оперативної пам'яті, дозволяючи дослідити механізми доступу до даних, кеш-влучань, кеш-промахів та узгодження даних між рівнями пам'яті.

Модель підтримує пряме відображення (Direct-Mapped Cache) та політику синхронізації **Write-Back**, що використовується в сучасних комп'ютерних системах. :contentReference[oaicite:1]{index=1}

---

## ✨ Реалізовані можливості

- читання даних з пам'яті;
- запис даних у кеш;
- визначення Cache Hit та Cache Miss;
- алгоритм прямого відображення кешу;
- алгоритм заміщення із використанням Write-Back;
- підтримка бітів **Valid** та **Dirty**;
- перегляд стану кеш-пам'яті;
- перегляд фрагмента оперативної пам'яті;
- інтерактивне консольне меню.

## 🚀 Запуск

```bash
g++ main.cpp -o cache-simulator
./cache-simulator
```

Після запуску доступне інтерактивне меню для виконання операцій із кеш-пам'яттю.
